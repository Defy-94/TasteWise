界面截图目录
================================================
把小程序各页面的截图按以下文件名放进本目录，README 的「界面预览」一节会自动显示：

  home.png          首页（分类导航 / 搜索 / 菜品列表 / 小味浮窗）
  dish-detail.png   菜品详情（大图 / 介绍 / 份数加购 / 小味指引立绘）
  ai-chat.png       AI 助手对话（小味舞台区 / 流式回复 / 推荐卡片）
  cart.png          购物车
  user-center.png   用户中心
  admin.png         管理后台
  about.png         关于页

截图建议
------------------------------------------------
  * 用微信开发者工具的模拟器逐页截图
  * 机型选 iPhone 6/7/8（375x667），比例统一
  * PNG 格式，宽度 750px 左右（2 倍图），单张控制在 300KB 以内
  * 七张合计建议不超过 2MB（这些图不参与小程序打包，只用于 README 展示）
